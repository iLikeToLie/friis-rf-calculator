FRIIS RF LINK & INTERFERENCE CALCULATOR
VERSION HISTORY

Maintenance rule:
Add one entry for every released workbook or web version. Record the version,
file or deployment, release date, primary function, key changes, and limitations.

-------------------------------------------------------------------------------
Version 1
File: Friis_RF_Link_and_Interference_Calculator.xlsx
Date: 2026-07-29

Function:
Preliminary free-space RF link-budget and interference-screening calculator.

Key changes:
- Added the main Friis calculator with received power, FSPL, sensitivity margin,
  interference-threshold margin, and screening status.
- Added a distance sweep with received-power and threshold curves.
- Added a ten-scenario antenna-placement comparison.
- Added instructions, equations, definitions, and model limitations.

-------------------------------------------------------------------------------
Version 2
File: Friis_RF_Link_and_Interference_Calculator_v2.xlsx
Date: 2026-07-29

Function:
Extended the calculator with antenna-gain sensitivity analysis.

Key changes:
- Added Gain Plot with a Tx/Rx gain sweep selector.
- Added minimum gain, maximum gain, and gain-step controls.
- Added three editable comparison distances and corresponding power curves.
- Retained formula-driven sensitivity and interference-threshold references.

-------------------------------------------------------------------------------
Version 3
File: Friis_RF_Link_and_Interference_Calculator_v3.xlsx
Date: 2026-07-29

Function:
Corrected Gain Plot chart labeling.

Key changes:
- Removed static distance text from chart-series names.
- Standardized the legend to Curve 1, Curve 2, and Curve 3.
- Kept the actual editable comparison distances visible in the sheet controls.

-------------------------------------------------------------------------------
Version 4
File: Friis_RF_Link_and_Interference_Calculator_v4.xlsx
Date: 2026-07-30

Function:
Added native Excel 1D antenna-pattern and off-axis directional-gain modelling.

Key changes:
- Added Antenna Setup with Manual gain, Manual off-axis, and Geometry-derived
  gain-source modes for Tx and Rx.
- Added local-coordinate geometry for path bearing, elevation, and off-axis angles.
- Added editable Tx/Rx horizontal and vertical 1D pattern tables.
- Added linear pattern interpolation in dB without extrapolation.
- Added Horizontal only, Vertical only, and explicit H + V approximation modes.
- Added Pattern View with selectable antenna/plane and a pattern-cut chart.
- Integrated active directional gains into Calculator and Distance Plot.
- Updated Gain Plot so the swept value replaces one active directional gain while
  the other remains fixed.
- Added optional active-pattern gains to Placement Comparison.
- Expanded instructions, warnings, conventions, and limitations.
- Preserved Version 3 results when both antennas remain in Manual gain mode.

Important limitation:
The included antenna patterns are illustrative placeholders. Replace them with
manufacturer or measured data before using pattern-derived results for engineering
decisions. The model uses 1D cuts, not a full 2D or 3D radiation pattern.

-------------------------------------------------------------------------------
Web Version 1 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-08-19

Function:
Responsive browser version of the Version 3 calculator for GitHub Pages.

Key changes:
- Converted the Version 3 Friis calculations into a tested TypeScript engine.
- Added web views for the main calculator, distance sweep, Tx/Rx gain sweep, and
  editable placement comparison.
- Made all three gain-curve distances dynamic in controls and chart legends.
- Added device-local autosave, JSON scenario import/export, and reset controls.
- Added an automated GitHub Pages build, test, and deployment workflow.

Important limitation:
The web version follows workbook Version 3 and therefore does not include Version 4
antenna-pattern, geometry-derived off-axis, or directional-gain features.

-------------------------------------------------------------------------------
Web Version 1.1 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-08-19

Function:
Separated intended-link assessment from interference-avoidance screening.

Key changes:
- Added a Link objective toggle with Desired communication and Interference
  avoidance modes.
- Desired communication status now uses receiver sensitivity and fade-margin
  target without penalizing a strong intended signal as interference.
- Interference avoidance status now uses the interference screening threshold.
- Applied the selected objective to the main calculator and placement comparison.
- Added migration for existing browser-saved and exported Version 1 scenarios.
- Added automated tests covering both objective modes.

Important limitation:
The desired-link mode uses link margin versus sensitivity, not true SNR. True SNR
would require receiver noise-floor information or bandwidth and noise figure.

-------------------------------------------------------------------------------
Web Version 1.2 (based on workbook Version 3)
Deployment: https://iliketolie.github.io/friis-rf-calculator/
Date: 2026-08-19

Function:
Added a live visual representation of the calculated Tx-to-Rx link.

Key changes:
- Added dynamic Tx and Rx antenna endpoints with identifiers, power, and gain.
- Added the calculated Tx-to-Rx distance, FSPL, frequency, and total link loss.
- Added endpoint cable losses and path-level polarization, environmental, and
  miscellaneous losses.
- Added stylized antenna beams and animated signal packets whose colour follows
  the selected objective and resulting status.
- Added receiver sensitivity and interference-threshold markers beside a dynamic
  received-power meter.
- Added responsive horizontal navigation for the link graphic on small screens.
- Preserved all Version 1.1 calculations and objective logic.

Calculation scope:
Version 1.2 is a visual enhancement and does not change the Version 1.1 RF power
or objective-status calculations.
